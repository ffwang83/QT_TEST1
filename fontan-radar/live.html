資料來源與使用原則

本頁不是模擬資料。每次按下「立即抓取真實標案」，會依公告日期向公開 API 取得實際政府電子採購網資料，再由 FONTAN 規則引擎篩選。g0v/OpenFun API 公開說明其資料來源為中華民國政府電子採購網，並提供 CORS；政府電子採購網本身則是行政院公共工程委員會維運的政府採購資訊入口。商業利用仍應依原始資料的授權與合理使用規範處理，投標前務必點入原始公告核驗。
